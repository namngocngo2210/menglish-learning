# menglish-learning

Website luyện tiếng Anh cho học sinh lớp 6–9: trắc nghiệm đọc + viết theo lớp, chủ đề và luyện thi vào lớp 10. Miễn phí, chuẩn SEO.

**Stack**: Next.js (FE) · Go + Gin (BE) · PostgreSQL · Redis · Docker.
