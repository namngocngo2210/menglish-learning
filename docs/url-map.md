# URL map (public URLs, English)

Generated by `scripts/gen-url-map-doc.ts` from `packages/core/src/url-map.ts` (single source of truth). Do not edit by hand.

Since 2/11/2026 every public URL is English, lowercase and hyphenated. Page titles, H1 and descriptions stay Vietnamese. Internal ids
(skill `doc-hieu`, topic `thi-hien-tai-don`, content test slug `lop-6/ngu-phap/<topic>/de-1`) are stable data keys in content, DB, API and rooms;
only the URL segments are translated, at the boundary (`@bj/core`: `gradePath`, `skillPath`, `topicPath`, `testPath`, `testSlugPath`, `legacyToPublicPath`).

## Redirects

Every old URL answers **one** `301` to the new URL (query string kept, trailing slash folded into the same hop), from `web/proxy.ts`
(Next app layer; not Caddy). Unknown old-looking URLs 404. The redirects are permanent: never remove them.
Earlier redirects in `web/content/legacy-redirects.json` (retired topic pages -> mixed page) are mapped to the new URL in the same single hop.
