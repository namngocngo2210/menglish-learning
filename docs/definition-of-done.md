# Definition of Done (một trang)

Dùng cho dev (tự kiểm trước khi mở PR), tester và reviewer (kiểm lại từng dòng, ghi PASS/FAIL + bằng chứng vào thẻ). Chi tiết và lý do: [engineering-standards.md](engineering-standards.md). Mục đánh dấu *khi áp dụng* chỉ kiểm nếu PR đụng tới.

## A. Phạm vi và quy trình
- [ ] Một yêu cầu = một nhánh = một PR; PR nhỏ, một mục đích; tên nhánh `<type>/<kebab>`
- [ ] Commit: `type(scope): summary`, tiếng Anh; **không** `Co-Authored-By`/"Generated by" (`npm run commits:check`)
- [ ] Mô tả PR tiếng Việt theo mẫu: cái gì/vì sao/cách kiểm thử/rollback
- [ ] Không merge/deploy từ agent; chạm máy chủ (Caddy, compose chạy thật, cron, secret) chỉ khi chủ duyệt riêng
- [ ] Quyết định kiến trúc/dependency nặng/hạ sàn chất lượng có ADR

## B. Chất lượng mã (máy kiểm — CI xanh)
- [ ] `npm run check` ở gốc xanh (lint, format, typecheck, boundaries, licenses)
- [ ] lint + typecheck + test của package đã đụng xanh
- [ ] Không `any`, `@ts-ignore`, `eslint-disable` không lý do; không nới/tắt quy tắc để qua
- [ ] Không vòng phụ thuộc; `packages/core` không I/O; web không import api (`deps:check`)
- [ ] CI jobs xanh: repo-checks, commits, tests, audit, gitleaks (+ `ci.yml` cho `web/`)

## C. Test
- [ ] Mỗi thay đổi hành vi có test; test thất bại khi bỏ thay đổi (không test rỗng)
- [ ] Coverage không dưới sàn: core ≥ 90%, api ≥ 80%
- [ ] Không flaky: không sleep thật, không phụ thuộc thứ tự/giờ/mạng ngoài
- [ ] *Khi áp dụng:* contract test OpenAPI; migration up→down→up; import-parity = 0 chênh, chạy lại idempotent; e2e Playwright đường găng
- [ ] Tester đã chạy bộ đầy đủ qua `~/.local/bin/heavy -m 1800M` (không hai bộ song song)

## D. API (khi áp dụng)
- [ ] Route `/api/v1`, kebab, danh từ số nhiều; chỉ thay đổi cộng thêm trong v1
- [ ] zod ở mọi biên (`.strict()`, giới hạn kích thước); OpenAPI sinh cập nhật
- [ ] Lỗi là `application/problem+json` với `code` ổn định; không lộ stack/SQL
- [ ] Cursor pagination; `Idempotency-Key` cho POST thử lại được; header rate-limit; mã trạng thái đúng
- [ ] Route admin có guard (test liệt kê route → 401 khi thiếu phiên)

## E. Cơ sở dữ liệu (khi áp dụng)
- [ ] Migration SQL có up **và** down, một mối quan tâm, không sửa migration đã áp dụng
- [ ] FK có index; `timestamptz`; `text + CHECK` thay enum; không N+1; `EXPLAIN` truy vấn nóng
- [ ] Tương thích image api trước đó (expand → backfill → contract); quyền role tối thiểu
- [ ] Kiểu Kysely sinh lại, không sửa tay

## F. Bảo mật và riêng tư
- [ ] Không secret trong diff/log/ảnh; `.env.example` cập nhật, không giá trị thật (gitleaks xanh)
- [ ] Đầu vào, quyền, XSS, CSRF, SSRF (`safeFetch`), header theo bảng ASVS mục 5
- [ ] Không PII của học sinh (không email/tên/IP thô); log có redact
- [ ] `npm audit` high+ sạch; license trong allowlist; dependency mới có lý do (nặng ⇒ ADR)

## G. Vận hành và hiệu năng (khi áp dụng)
- [ ] Config qua zod lúc khởi động; `/healthz` + `/readyz`
- [ ] Trong ngân sách: p95 HIT < 100 ms; RSS web ≤ 384 MB, api ≤ 160 MB, worker ≤ 320 MB; Lighthouse SEO 100 / Perf ≥ 90 / A11y ≥ 95 / BP ≥ 95
- [ ] Container tạm của agent đã dừng (`--rm --label hermes.task=…`)

## H. Nội dung, SEO, tài liệu
- [ ] Chuỗi người dùng bằng tiếng Việt có dấu; code/comment/log bằng tiếng Anh; slug không dấu
- [ ] Trang công khai: checklist SEO của CLAUDE.md (metadata, canonical, JSON-LD, sitemap, nội bộ link)
- [ ] Không nội dung do AI sinh/sao chép; nội dung crawl qua quarantine → chủ duyệt
- [ ] Docs/ADR/CHANGELOG cập nhật khi đổi hành vi hoặc quyết định

**Kết quả:** PASS chỉ khi mọi mục áp dụng được tick; mục bị bỏ qua phải ghi lý do trong thẻ. Mục [D] (chỉ tài liệu) do reviewer kiểm tay; một quy tắc [E] bị nới trong diff là finding chặn.
