# Lộ trình

## Giai đoạn 1 — Trắc nghiệm đọc + viết, miễn phí (≈ 4–5 tuần)

1. **Nền tảng**: monorepo, Docker compose, Postgres + Redis, migration, khung Next.js + Gin, middleware bảo mật và rate limit, SEO nền (metadata, sitemap, robots, JSON-LD), CI (lint, test, govulncheck, npm audit, gitleaks, Lighthouse CI).
2. **Crawler + ngân hàng câu hỏi**: nguồn hợp pháp ([content-sources.md](content-sources.md)), sinh câu theo quy tắc, phân loại, ≥ 2.000 câu.
3. **Trộn đề + trang đề**: mixer tất định, trang lớp/kỹ năng/chủ đề/đề, thi vào lớp 10, chấm điểm phía server, giải thích + ghi nguồn, quảng cáo AdSense chế độ trẻ em.
4. **Lên beta.meducation.vn**: Caddy trỏ về `web`/`api`, bỏ `noindex`, đăng ký Google Search Console, gửi sitemap.

Tiêu chí xong: Lighthouse đạt ngưỡng, làm đề trọn vẹn trên mobile, sitemap được Google đọc.
