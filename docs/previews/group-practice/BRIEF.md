# Design brief — Luyện tập nhóm (static mockups)

Design reference only. Static HTML + Tailwind, no JS logic needed (tiny inline JS for tab/state toggles is NOT required). Not production code. All names/scores are **sample data** and every screen must show a small visible label "Dữ liệu mẫu" (sample data) near the sample content.

## Direction — BeeJunior brand (authoritative direction, updated 31/10 by owner)
- Brand name **BeeJunior**. Use the real logo `assets/beejunior-logo.png` (bee with glasses + wordmark, already cropped, 707x365) in the header (height ~40px desktop / 32px mobile, `alt="BeeJunior"`); the bee may be reused in empty/error states.
- Palette: brand yellow `#ffc001`, brand sky-blue `#10b7eb`, ink `#291e1c` (for text/dark surfaces). ACCESSIBLE shades: primary CTA = yellow `#ffc001` background + ink `#291e1c` text; secondary/links/selected = deep sky `#0a6f96` (white text OK, >= 4.5:1); `#10b7eb` only decorative (borders, fills behind ink text, large icons). Surfaces: cream `#fffbea`, light sky `#eef9fe`, white cards, borders ink at 15–20% (2px ink for emphasis). Success/error keep green `#166534` / red `#b91c1c` text with icons. Use only the BeeJunior palette and semantic success/error colors; avoid a generic grey interface.
- Font: Be Vietnam Pro, local only (`web/fonts/*.woff2`, weights 400 and 700 only, use `@font-face` with relative url to `../../../web/fonts/`). No CDN, no external requests, no images from the network. Icons: inline SVG (Lucide-style, stroke 2) with `aria-hidden`, icon-only buttons have `aria-label`.
- Audience: Vietnamese students grade 6–9 (11–15 yo). Friendly, energetic but grown-up. NOT preschool cartoon, NOT grey SaaS. Rounded 12–16px cards, 2px ink-tinted borders, soft shadow, generous spacing, large readable type (base 16px, line-height >= 1.5, question text 20px+).
- Touch targets >= 44px height/width, visible focus ring (3px `#291e1c` offset 2px) shown on at least one element per screen, contrast >= 4.5:1. Respect reduced motion (no animation needed).
- Language: Vietnamese UI copy, lang="vi". Use proper Vietnamese diacritics.
- Header: simple site header (BeeJunior logo, nav: Lớp 6–9, Thi vào 10, Luyện tập nhóm active). Footer: slim. On play/waiting screens header is reduced (no nav, no ads). Ads: only the landing page and results page may show one ad placeholder box labelled "Quảng cáo (không cá nhân hóa)"; NEVER on lobby/play/waiting screens.
